# 🚀 RefactorX

**Write cleaner code. Simplify development.**

RefactorX is a modern web application built with React and Vite, designed with a focus on a clean user interface, reusable components, and an efficient development workflow.

🔗 **Repository:** [RefactorX](https://github.com/ab-anamika26/RefactorX)

## ✨ Features

- ⚛️ **React** — Component-based user interface development.
- ⚡ **Vite** — Fast development server and optimized production builds.
- 🎨 **Lucide React** — Clean and customizable icons.
- 🧩 **Reusable Components** — A modular approach to frontend development.
- 🛠️ **Modern Tooling** — A streamlined workflow for developing and building the application.

## 🚀 Getting Started

Follow these steps to run RefactorX locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ab-anamika26/RefactorX.git
```

**2. Navigate to the project directory**

```bash
cd RefactorX
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.

## 📦 Production Build

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
